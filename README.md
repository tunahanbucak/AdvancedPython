# 🐍 Advanced Python Tutorial & Quiz (Python İleri Düzey Özellikler Rehberi)

Bu repo, Python'ın ileri seviye özelliklerini (Decorators, Property Decorators, Static/Class Methods, Abstract Methods, Overload, Final, Override ve Decorator Stacking) öğrenmek, pekiştirmek ve test etmek amacıyla hazırlanmış kapsamlı bir Türkçe eğitim rehberi ve etkileşimli sınav projesidir.

---

## 📌 İçerik ve Proje Yapısı

- **`PYTHON_GELISMIS_OZELLIKLER_REHBERI.md`**: Tüm ileri düzey konuların detaylı teorik anlatımı, günlük hayattan benzetmeler, kullanım alanları ve özet karşılaştırma tablosu.
- **`advanced_python_rehberi.py`**: Detaylı Türkçe açıklamalarıyla birlikte temiz kod örneklerini içeren çalıştırılabilir Python betiği.
- **`main.py`**: Konuların sade ve özgün kod uygulamaları.
- **`quiz.py`**: Kazanılan bilgileri ölçen ve anında geri bildirim veren 10 soruluk etkileşimli terminal sınav uygulaması.

---

## 🚀 Hızlı Başlangıç

Projeyi bilgisayarınıza indirip terminal üzerinden hemen çalıştırabilirsiniz:

```bash
# Projeyi klonlayın
git clone https://github.com/KULLANICI_ADINIZ/AdvancedPython.git

# Proje dizinine gidin
cd AdvancedPython
```

### 1. Eğitim Betiğini Çalıştırma
```bash
python3 advanced_python_rehberi.py
```

### 2. Etkileşimli Sınavı (Quiz) Başlatma
```bash
python3 quiz.py
```

## 📚 Kapsanan Konular

1. **Basic Decorators** (`@decorator` mantığı, sarıcı fonksiyonlar, `*args, **kwargs`)
2. **Property Decorators** (`@property`, `@setter`, `@deleter`, kapsülleme ve veri doğrulama)
3. **Static Methods** (`@staticmethod` ve bağımsız yardımcı fonksiyonlar)
4. **Class Methods** (`@classmethod`, `cls` parametresi, fabrika metotları)
5. **Abstract Methods** (`@abstractmethod`, `ABC`, arayüz/sözleşme mimarisi)
6. **Function Overloading** (`@overload` ve tip denetleyici desteği)
7. **Final Classes & Methods** (`@final` ile türetilmeyi ve ezilmeyi engelleme)
8. **Override Decorator** (`@override` ile güvenli metot ezme)
9. **Bonus: Stacking Decorators** (Çoklu dekoratörlerin aşağıdan yukarıya çalışma sırası)
